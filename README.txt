PORTFOLIO NGUYỄN HỮU TRỌNG — GitHub Pages

Cấu trúc:
- index.html: trang portfolio
- assets/: CSS và toàn bộ hình ảnh

Cách đăng công khai:
1. Tạo repository mới trên GitHub.
2. Upload index.html và toàn bộ thư mục assets (không chỉ upload riêng các file bên trong).
3. Vào Settings → Pages.
4. Ở Build and deployment, chọn Deploy from a branch.
5. Chọn branch main và folder /(root), rồi Save.
6. Chờ GitHub Pages xuất bản website.

Lưu ý:
- Giữ nguyên cấu trúc assets/ để đường dẫn ảnh hoạt động.
- Không đổi tên file ảnh nếu chưa cập nhật đường dẫn trong index.html.
- Nếu repository là public, toàn bộ hình ảnh và nội dung portfolio sẽ công khai.
