PORTFOLIO NGUYỄN HỮU TRỌNG — GITHUB PAGES

CẤU TRÚC BẮT BUỘC:
- index.html  (đặt ở thư mục gốc repository)
- assets/     (đặt cạnh index.html, không đổi tên file)

CÁCH CẬP NHẬT:
1. Sao lưu index.html và assets cũ trên GitHub.
2. Chép index.html trong gói này vào thư mục gốc repository.
3. Đồng bộ toàn bộ thư mục assets trong gói này vào thư mục assets ở cùng cấp với index.html.
4. Commit và push lên nhánh main.
5. GitHub repository > Settings > Pages: Deploy from a branch, branch main, folder /(root).
6. Mở URL GitHub Pages và tải lại mạnh (Cmd+Shift+R trên Mac).

LƯU Ý:
- Không đặt index.html bên trong thư mục assets.
- Không đổi tên hoặc viết hoa/thường tên ảnh/video; GitHub Pages phân biệt chữ hoa/thường.
- Các đường dẫn trong HTML đều tương đối dạng assets/ten-file.
