CÁCH CẬP NHẬT GITHUB PAGES
1. Giải nén ZIP này.
2. Sao lưu thư mục repository cũ.
3. Chép index.html vào thư mục gốc repository.
4. Đồng bộ toàn bộ thư mục assets đi kèm vào thư mục assets cùng cấp với index.html.
5. Mở GitHub Desktop, kiểm tra thay đổi, Commit to main rồi Push origin.
6. Chờ GitHub Pages hoàn tất triển khai, sau đó tải lại website bằng Command + Shift + R.

Lưu ý: Không đổi tên file ảnh/video và không đặt index.html bên trong assets.
